# 历史补丁（只读，不要执行）

这些 `apply-*.py` 是 2026-11-24 那天逐轮改 `src/index.html` 时用的「字符串替换」脚本：读进整个 HTML，按精确匹配换掉某一段，再写回。

它们的效果**已经全部进了 `src/index.html`**。留在这是为了回看当时某一轮到底改了哪几句。

为什么不能重跑：

- 匹配的是**旧版**的字符串，新版早就没了，一跑就报「找不到锚点」；
- 就算侥幸匹配上，也是把已经改好的地方再覆盖一遍，容易把后续几轮的调整冲掉；
- 几个脚本之间有先后依赖（比如 `polish3` 依赖 `polish2` 改过的结构），顺序错就炸。

以后要改界面：用 `npm run where 关键词` 找位置，直接编辑 `src/index.html`，别再写这种补丁脚本了。
