## 版本一 · 发群 / 发朋友（约 300 字）

用了一年多的小工具，自己写的桌面版（Windows 和 Mac 都有），记一次训练大概三分钟。

它只干一件事：把「今天练了什么、多重、几组几次」变成一段能直接粘贴的文字，顺手存进日历。

三个我觉得最省事的地方：

1、一周安排——周一到周日各配一套动作，到健身房打开就是今天的菜单，不用再想练什么。

2、补记录——昨天忘了记，点「补记录」→ 整月日期变绿 → 点昨天 → 照常填，记录落在昨天那天，不是今天。

3、关键重量——勾上之后日历会变深黄，一个月翻下来，哪天冲了新重量一眼就看到。

另外还有：54 个内置动作（认俗称，搜「平板」也能找到卧推）、可以自己加动作、同一动作能每组单独设次数（递减组）、能一键复制记录文字、数据全在本机不联网也不用注册。

详细用法我整理成一张图了，见附件。要装的找我要安装包。

## 发给朋友时可能被问到的

**要不要联网 / 要不要注册？**
都不用。数据存在本机，卸载重装还在（除非手动清数据目录）。

**手机上能用吗？**
目前是桌面版（Windows / Mac）。手机上用的话，可以把复制出来的文字存备忘录。

**收费吗？**
自己用的工具，不收费。

**支持哪些动作？**
内置 66 个（胸背腿肩手臂），不够可以自己加，加的时候写个别称，以后搜俗称也能找到。
