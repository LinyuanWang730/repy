# 发布网站

站点的职责只有一个：让人能下到 Repy。另外附带一个在线体验版，不装也能先看看界面。

## 为什么分两块放

| 放什么 | 放哪 | 原因 |
|---|---|---|
| 落地页、在线体验版（共约 1 MB） | Cloudflare Pages（`site/` 目录） | 免费、静态请求不限量 |
| 三个安装包（各 70–79 MB） | GitHub Releases | **Pages 单个文件上限 25 MiB**，exe 放不进去 |

这不是凑合，是 Cloudflare 官方给的做法。所以站点里只管页面，安装包一律外链。

## 一次性准备（只做一次）

### 1. 建一个只装安装包的公开仓库

1. 打开 <https://github.com/new>
2. 仓库名填 `repy-downloads`
3. 选 **Public**（私有仓库的附件别人下载不了，会跳登录页）
4. 勾上 "Add a README file"，点 Create

源码不用上去，还留在 iCloud 那个裸仓库里。这个仓库除了安装包什么都不放。

### 2. 把占位符换成你的用户名

`site/index.html` 里有三处

```
https://github.com/YUANZI/repy-downloads/releases/latest/download/...
```

把 `YUANZI` 换成你的 GitHub 用户名。改完 `5-发布网站.bat` 会自己检查有没有漏，没改会拦住不让发。

### 3. 登录 Cloudflare

命令行跑一次：

```
npx wrangler login
```

浏览器弹出来点一下授权。之后就不用再登了。

## 每次发版

| 步骤 | 做什么 |
|---|---|
| 1 | `npm run bump 2.1.3` 改版本号 |
| 2 | 双击 `2-打包出exe.bat` 出安装包 |
| 3 | `python scripts/pack-release.py` 生成 `dist/release/` 里三个定名文件 |
| 4 | GitHub 仓库 → Releases → Create a new release，Tag 填 `v2.1.3`，把三个文件拖进附件框，Publish |
| 5 | 双击 `5-发布网站.bat` |

第 5 步内部先跑 `npm run site:sync`（把版本号、更新日志、在线版从 `src/index.html` 同步过来），再 `wrangler pages deploy`。

### 为什么文件名不能改

下载按钮写的是：

```
https://github.com/<用户名>/repy-downloads/releases/latest/download/Repy-Setup.exe
```

`releases/latest` 永远指向最新一版，前提是**每一版的附件都叫这个名字**。如果照着 electron-builder 的默认名传成 `Repy-2.1.3-Setup.exe`，下个版本一发布，落地页三个按钮全部 404。`pack-release.py` 就是干这个改名的活。

## 站点目录

```
site/
├── index.html            落地页（版本号和更新日志由 sync 脚本生成，别手改标记之间的内容）
├── _headers              缓存策略
├── assets/               图标、两张截图
└── app/
    ├── index.html        在线体验版 = src/index.html + 右下角说明卡片
    └── assets/           机器人图、咖啡码
```

`site/app/index.html` 是**生成出来的**，不要直接改 —— 下次 `site:sync` 会被覆盖。要改里面的东西，改 `src/index.html` 或 `scripts/site-parts/web-note.html`。

落地页里这两处也别手改，会被覆盖：

- `<span class="ver" data-site-ver>` 里的版本号
- `<!-- RELEASES:BEGIN -->` 到 `<!-- RELEASES:END -->` 之间的日志

## 排错

| 现象 | 原因和解法 |
|---|---|
| `Asset too large` / `exceeds 25 MiB` | 有安装包被放进了 `site/`。exe 只能进 Release |
| 点下载 404 | Release 里的附件名不是 `Repy-Setup.exe` / `Repy-Portable.exe` / `Repy-Portable.zip` |
| 页面还是旧版本号 | 浏览器缓存，`Ctrl+F5` 强刷 |
| 国内打不开 `repy.pages.dev` | `pages.dev` 在国内经常被 DNS 污染。绑自己的域名（Cloudflare 面板 → Pages 项目 → Custom domains）就能正常访问，站点代码不用改 |
| 双击 exe 被拦 | 没买数字签名证书，正常。点「更多信息 → 仍要运行」；页面上的安装说明就是写这个的 |
| 下载速度只有几十 KB/s | GitHub 在国内的速度波动大。急用可以挂加速，或者以后有条件换对象存储 |

## 在线体验版的边界

`src/index.html` 里所有 `window.desktop` 的调用都带 `?.` 或 `if (!window.desktop)` 兜底，所以浏览器里能跑。但下面这些在在线版里是降级的：

- 「打开数据目录」→ 提示"桌面版里才能打开文件夹"
- 「导出运行日志」→ 改成复制到剪贴板
- 「检查更新」「覆盖升级」→ 提示"桌面版里才能检查更新"
- 数据存在浏览器 localStorage，清缓存就没了

右下角那张卡片就是提醒这件事，关掉一次后不再弹（每个浏览器各自记）。
